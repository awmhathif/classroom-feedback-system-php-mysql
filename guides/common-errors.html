Common errors and exact fixes

These are the errors people hit most with XAMPP, PHP and MySQL, and the ones this project can show. The numbers in brackets are roughly how many people viewed that question on Stack Overflow. You're not the first.

Find the real error first. A blank page hides it. Check display_errors=On in php.ini (XAMPP → Apache → Config → PHP (php.ini)), restart Apache, refresh. The newest errors are also at the bottom of C:\xampp\apache\logs\error.log.

XAMPP won't start

Apache: "Port 80 in use" or "Apache shutdown unexpectedly" (2.4 million views)

Another program owns port 80. The XAMPP log shows which one ("by PID 4" means Windows itself, usually IIS).

  • Windows IIS: Windows key → type services → open it → find World Wide Web Publishing Service → right click → Stop → double click → Startup type Disabled → OK.
  • Skype (old versions): Skype settings → Advanced → Connection → untick "Use port 80 and 443".
  • Or move Apache: XAMPP → Apache → Config → httpd.conf → find Listen 80 → change it to Listen 8080 → save → start. Use http://localhost:8080/classroom-feedback/ from now on.

MySQL: "MySQL shutdown unexpectedly" (3 million views)

Usually after the PC turned off suddenly, or because another MySQL is already running. Don't delete the data folder: your database is inside it.

  1. Windows key → services → stop any other "MySQL" or "MariaDB" service. Try to start MySQL in XAMPP.
  2. Still failing: copy C:\xampp\mysql\data somewhere as a backup.
  3. In C:\xampp\mysql\data, rename aria_log_control to aria_log_control.old. Try to start.
  4. Still failing: rename data to data_old. Make a copy of C:\xampp\mysql\backup and call it data. From data_old, copy your database folder (feedback_db) and the file ibdata1 into the new data. Start MySQL.
  5. Last resort for this project: import database.sql again. Everything comes back with the demo data (anything you typed on the site is lost).

MySQL: port 3306 in use

Another MySQL program (a MySQL Server install, WAMP, Laragon) is running. Stop it in Windows Services, or change XAMPP's port: XAMPP → MySQL → Config → my.ini → change both port=3306 lines to 3307. Then in includes/config.php use:

$conn = new mysqli("localhost", "root", "", "feedback_db", 3307);

The browser shows something wrong

"Not Found: The requested URL was not found on this server"

  • The folder isn't at htdocs/classroom-feedback/, or a file name is spelled differently. Teacher.php and teacher.php are different files on Mac and Linux.
  • You typed the address without .php.

"Forbidden: You don't have permission to access this resource" (2.7 million views)

You opened a folder with no index.php in it, or the project is outside htdocs. Open http://localhost/classroom-feedback/index.php.

The page shows PHP code, or the browser downloads the file

You opened it as a file (file:///C:/xampp/...) or Apache isn't running. Always use http://localhost/....

A completely blank white page (143K views)

A fatal PHP error with errors hidden. Turn on display_errors (top of this page), or read apache\logs\error.log.

"This site can't be reached" or "localhost refused to connect"

Apache isn't running. Start it in XAMPP.

The page has no styling (plain black text on white)

css/style.css is missing or in the wrong folder. It must be htdocs/classroom-feedback/css/style.css. Copy it again from steps/step-NN/css/ for the step you are on.

"Not found: This page doesn't exist, or it isn't yours."

This is the project's own page. The address has an id that doesn't exist, or it belongs to another teacher's class, or (for students) a class you aren't in or a draft round. Go back home and use the links.

PHP errors

"Warning: Undefined variable $x" or "Undefined array key 'name'" (2.2 million views)

You used a variable before giving it a value, or read a form box that wasn't sent. This project reads every box with post(), which gives "" for a missing box:

$name = post("name");   // "" if the box wasn't sent

If you add a new form box, read it the same way.

"Cannot modify header information: headers already sent by (output started at ...:1)" (2 million views)

header() (used by go()) and session_start() (in config.php) must run before anything is printed. The message says which file and line printed first. Usually:

  • a space or an empty line before <?php at the very top of a file
  • an empty line after a PHP end tag at the end of config.php or functions.php (that is why those two files have no end tag)
  • an echo you added for testing
  • the file was saved "with BOM": VS Code bottom bar → click UTF-8 with BOM → Save with Encoding → UTF-8

"session_start(): Session cannot be started after headers have already been sent"

Same cause as above: require "includes/config.php"; must come before any HTML.

"Fatal error: Call to undefined function e()" (or go(), flash(), require_role()...)

The page is missing require "includes/config.php"; at the top (it loads functions.php), or you made a typo in the function name, or your functions.php is from an earlier step. Compare it with steps/step-NN/includes/functions.php.

"Fatal error: Cannot redeclare function ..."

The same function is written twice: once in functions.php and once in a page, or functions.php is loaded twice. Search the project (Ctrl+Shift+F) for function name(.

"Fatal error: Call to undefined method mysqli::execute_query()"

Your PHP is older than 8.2. Check at http://localhost/dashboard/phpinfo.php. Install a newer XAMPP.

"Fatal error: Uncaught mysqli_sql_exception: ..."

PHP stops on any database error and tells you exactly what MySQL said. Read the part after mysqli_sql_exception::

  • Unknown database 'feedback_db': import database.sql (phpMyAdmin → Import, or the SQL tab).
  • Table 'feedback_db.x' doesn't exist: you didn't run the SQL of the step you are on. Import that step's database.sql.
  • Unknown column 'x' in 'field list': the column name in your PHP doesn't match the table, or your database is from an older copy. Check the spelling in phpMyAdmin, or import database.sql again.
  • You have an error in your SQL syntax ... near '...': look just before the quoted text: usually a missing comma, a missing quote, or a word like ORDER stuck to the previous word because you joined two strings without a space.
  • Column count doesn't match value count: an INSERT has a different number of columns, ? and values. Count all three.
  • Duplicate entry 'x' for key 'email' (or 'join_code'): that value already exists, and the column is UNIQUE.
  • Duplicate entry '3-5' for key 'PRIMARY' in enrolments or participations: a student joined the same class, or answered the same round, twice. The project uses INSERT IGNORE there so this never shows; if you see it, the word IGNORE is missing.
  • Cannot add or update a child row: a foreign key constraint fails: you saved something for a user, class or round that doesn't exist. Most often: you imported the database again while logged in, so your session points at a user that is gone. Log out and in again.
  • Cannot delete or update a parent row: you deleted a user, class or round in phpMyAdmin while other rows still point to it. The site itself refuses this with a message.
  • Data truncated for column 'status' (or 'role', 'type'): the value isn't one of the words the ENUM allows. Check the spelling: draft, open, closed; student, teacher; rating, comment.
  • Access denied for user 'root'@'localhost' (581K views): root has a password on this PC. Put it in config.php, as the third value of new mysqli(...).

"This form has expired. Go back, reload the page and try again."

Our CSRF check. The session that held the code was lost (Apache restarted, cookies cleared, or you opened the form in another browser). Reload the form page and send again. If it happens on every form, a page is missing require "includes/config.php", so session_start() never runs.

Things that "don't work" without an error

Problem Cause and fix
CSS changes don't show The browser keeps an old copy. Press Ctrl+F5.
Logged in, but the next page forgets That page doesn't include config.php, so session_start() never ran.
The demo logins don't work The demo users weren't imported, or a password hash was cut when you copied (each is exactly 60 characters). Import steps/step-01/database.sql. Every demo password is password123.
Everything you typed on the site is gone You imported a database.sql again. It always starts fresh with the demo data.
Sign up as a teacher says the code is wrong The code is TEACHER_CODE in includes/config.php (SCHOOL2026 unless you changed it). Capital letters matter.
"No class has this code" Check the letters with the teacher. New codes never use I, L or O, because they look like 1 and 0. Small letters are fine: they are made capital.
Open round for students is greyed out The class has fewer than 4 students. The orange card above says how many it has. Students join with the join code.
Open round says a question is too short Every question needs 5 to 200 letters. The empty one is marked in red. Write it or remove it.
"The closing time must be in the future" for a time that is The computer's clock or time zone is wrong. Times are checked with MySQL's clock, which comes from the computer.
A round is still open after its closing time It closes on the next page load (any page, any user). Refresh.
A student can't see a round It is still a draft, the student isn't in that class, or they already answered (it is under Done).
Results say "Not enough responses" Fewer than 4 students answered. This is the anonymity rule and can't be changed after closing. Next time, give more time or remind the class.
Removed a student but their answers still count On purpose: answers have no student id, so nobody can find which ones were theirs.
A student doesn't see the class averages The teacher didn't tick "Also show students the class average", or the round has fewer than 4 answers.
Tamil or Sinhala text shows as ??? or strange letters The database was imported with the wrong character set. database.sql starts with SET NAMES utf8mb4; keep that line. On the command line, add --default-character-set=utf8mb4.
The CSV opens in Excel with strange letters The line in csv.php that writes "\xEF\xBB\xBF" (the BOM) is missing. It tells Excel the file is UTF-8.
No Copy code button on the class page Browsers allow copying only on localhost or https. On another address (for example your PC's IP address from a phone) the button hides itself. Type the code instead.
No "Are you sure?" box, no answer counter, no letter counter js/app.js isn't loaded. The pages still work without it. Check the <script> line in footer.php, and press F12 → Console for errors.
The message at the bottom right disappears It hides itself after 3 seconds, on purpose.
phpMyAdmin says "Access denied for 'pma'" XAMPP's phpMyAdmin settings got changed. Reinstall XAMPP, or reset phpMyAdmin\config.inc.php from a fresh XAMPP download.

Errors from the forgot password chapter

Only if you built it from customise-ideas.html:

Problem Cause and fix
No file appears in C:\xampp\mailoutput The sendmail_path line in php.ini still starts with ;, or Apache wasn't restarted after the change. Also look in C:\xampp\apache\bin\mailoutput: the file goes into the folder Apache was started from.
"Failed to connect to mailserver at localhost port 25" Same cause: PHP is trying to send real email because sendmail_path isn't set.
Gmail: "SMTP Error: Could not authenticate" You used your normal Gmail password. Gmail needs an app password (16 letters), which needs 2 Step Verification on that Google account.
Gmail: "Could not connect to SMTP host" No internet, a firewall blocks port 587, or Host is spelled wrong.
Class "PHPMailer\PHPMailer\PHPMailer" not found The 3 PHPMailer files aren't in includes/PHPMailer/, or the require lines point to the wrong place.
The link says "This link doesn't work" It is more than 30 minutes old, it was used already, or a newer link was sent after it. Ask for a new one.
The link opens the wrong site APP_URL in config.php doesn't match where your project is (for example you use port 8080).

Still stuck?

  1. Compare your file with the same file in steps/step-NN/ for the step you are on. VS Code can show the differences: right click your file → Select for Compare, right click the other → Compare with Selected.
  2. Copy that whole step folder into htdocs/classroom-feedback, import its database.sql, and carry on from the next step. (Importing resets the demo data, so some Run it texts may show slightly different numbers.)
  3. Search the exact error message in quotes. Almost every error here has a Stack Overflow answer.
