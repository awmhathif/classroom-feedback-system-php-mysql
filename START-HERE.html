Before you start

Get your computer ready

Goal: by the end of this chapter, XAMPP and VS Code are installed and you have an empty project folder.

You don't need to know programming to start. This chapter installs two free programs and checks they work. It takes about 20 minutes, most of it waiting for downloads.

What you are going to build

A website where teachers ask their class for honest feedback, and students give it without fear. It has two kinds of users:

  • Teachers make classes, share a 6 letter join code, run feedback rounds with ready questions or their own, see the results when a round ends (lowest rated question first), hide an abusive comment, and post a reply telling students what will change. They can also share the class averages with students.
  • Students join a class with its code, answer each round once, and read the teacher's reply.

The important rule is anonymity: the system saves that a student answered in one table, and what was answered in another table, with nothing that links the two. If fewer than 4 students answer a round, nobody sees any results at all.

A round moves through 3 stages: draft (the teacher is writing it) → open (students answer) → closed (results and reply). A closed round never opens again.

You build it in 9 steps. After every step the site works and you can open it in the browser. If a step goes wrong, the steps folder in this package has the full project as it should look after every step (steps/step-01 to steps/step-03), so you can copy that and carry on.

The finished project is about 2,050 lines of PHP, 580 lines of CSS and 145 lines of JavaScript. Each step adds between 90 and 550 lines, plus the SQL.

When you open a page, this happens: your browser asks for teacher.php → Apache (the web server) gives the file to PHP → PHP asks MySQL for the classes → PHP builds the HTML → the browser shows it.

XAMPP puts Apache, PHP and MySQL on your own computer, so you don't need the internet or a hosting account.

1. Install XAMPP

  1. Go to apachefriends.org and download XAMPP for your system (Windows, Mac or Linux).
  2. Pick a version with PHP 8.2 or newer. This project uses a PHP feature (execute_query) that older versions don't have.
  3. Run the installer. Keep the default choices. On Windows it installs to C:\xampp.
  4. If Windows asks about the firewall for Apache, click Allow.

2. Start Apache and MySQL

  1. Open the XAMPP Control Panel (Windows: Start menu → XAMPP Control Panel. Mac: Applications → XAMPP → manager-osx).
  2. Click Start next to Apache. Then click Start next to MySQL.
  3. Both names turn green.
  4. Open your browser and go to http://localhost. You should see the XAMPP welcome page.

If Apache doesn't turn green

Another program is using port 80. On Windows this is usually "World Wide Web Publishing Service" (IIS) or Skype.

  • Fix 1: press the Windows key, type services, open it, find World Wide Web Publishing Service, click Stop, and set Startup type to Disabled.
  • Fix 2: in XAMPP, Apache row → Config → httpd.conf. Find the line Listen 80 and change it to Listen 8080. Save, start Apache again, and from now on use http://localhost:8080/classroom-feedback/ instead of http://localhost/classroom-feedback/.

More fixes are in guides/common-errors.html.

If MySQL doesn't turn green, or says "shutdown unexpectedly"

Another MySQL is already running on port 3306, or XAMPP's database files got damaged when the PC turned off suddenly. The fix for both is in guides/common-errors.html → "MySQL shutdown unexpectedly". Don't delete the mysql\data folder.

3. Install VS Code

VS Code is the editor where you write the code. It is free.

  1. Go to code.visualstudio.com, download it and install it.
  2. Open VS Code. Go to File → Auto Save and tick it. Now every change is saved by itself.

4. Make the project folder

  1. Open the folder C:\xampp\htdocs (Mac: /Applications/XAMPP/htdocs). Everything inside htdocs can be opened in the browser through http://localhost/.
  2. Make a new folder inside it called classroom-feedback (small letters, no spaces).
  3. In VS Code: File → Open Folder → choose htdocs\classroom-feedback → Select Folder. If it asks "Do you trust the authors", click Yes.

The left side of VS Code (the Explorer) now shows your empty CLASSROOM-FEEDBACK folder. This is where you will make every file.

How to make a file in VS Code

Hover over the folder name on the left and click the small New File icon (a page with a +). Type the name, for example index.php, and press Enter.

To make a file inside a folder, type the folder name too: includes/header.php makes the includes folder and the file in one go.

How to use the code in this guide

Every code box has the file name on top and a Copy button.

  • New lines are marked with a green bar on the left and a bold line number. Lines without the bar were already in the file from an earlier step. The top of the box says which lines are new.
  • Removed lines are listed under the box when a step deletes or replaces something.
  • A long line wraps onto the next row inside the box. It is still one line in the file (it has only one line number).
  • The box always shows the whole file. If you typed the earlier steps, add only the marked lines. If you get lost, click Copy, click inside the file in VS Code, press Ctrl+A (select all), then Ctrl+V (paste). Mac: Cmd instead of Ctrl.

Type the code yourself. It is slower than pasting, but it is the only way you will remember it, and at your viva you will be asked to explain and change it. Read the explanation under each box before you type. If a line still isn't clear, guides/code-explained.html (in the full kit) explains every line of the finished project.

The 7 tables:

Table One row is Key columns
users One teacher or student email is UNIQUE, role is student or teacher
classes One class teacher_id says whose class it is, join_code is the 6 letters students type
enrolments One student in one class The two ids together are the PRIMARY KEY, so a student can't join twice
rounds One feedback round status is draft, open or closed; reply is the teacher's answer to the class
questions One question in a round type is rating (1 to 5) or comment
participations "This student answered this round" Round and student only. No time, so the order of answering isn't kept
answers One score or one comment No student id and no time. The id is a random number, so row order means nothing
  • The anonymity rule is in the tables. participations knows who answered. answers knows what was answered. No column links them, so nobody (not the teacher, not someone reading the database later) can match an answer to a student.

3. Two small functions

Make includes/functions.php:

1<?php
2// Small functions used on many pages.
3
4// ===== Showing things =====
5
6// Makes text safe to put in HTML (stops people adding their own HTML or scripts)
7function e($text)
8{
9 return htmlspecialchars((string) $text, ENT_QUOTES, "UTF-8");
10}
11
12// plural(1, "student") = "1 student", plural(2, "class", "classes") = "2 classes"
13function plural($count, $word, $many = null)
14{
15 return $count . " " . ($count == 1 ? $word : ($many ?? $word . "s"));
16}
  • e() is the most important function in the project. Any text a user typed can contain HTML, like <script>. htmlspecialchars() turns < into &lt;, so the browser shows the text instead of running it. Every time a page prints something a user typed, it goes through e(). This stops an attack called XSS (cross site scripting).
  • plural() writes "1 student" but "2 students". $many ?? $word . "s" means: use $many if it was given, otherwise add an s. "class" needs plural($n, "class", "classes").

  • csrf_field() and check_csrf() stop another website from sending forms as you.   • one() runs a query that gives back one value, like a count.
  • execute_query($sql, [$values]) is how every query in this project gets user input. The ? in the SQL is filled with the value by MySQL, never glued into the SQL text. This stops SQL injection, where someone types SQL into a form box.

  • log_in() calls session_regenerate_id(true) first. It gives the visitor a new session id at the moment they log in, so an id someone else knew from before is useless.
